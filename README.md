# SmartCalculator

## El proyecto se ha estructurado en base a una aplicación web con tres paginas interconectadas:

La pagina de inicio que es el index.html  que es practicamente la presentación del sistema.
La pagina cal_consumo_electronico.html es donde podremos encontrar las herramientas para poder calcular o 
estimar los gastos energéticos y sus costos.

La pagina calculadora de ley de ohm (calculadora_ohm.html), es lo que nos va a permitir calcular voltaje, 
corriente o resistencia a partir de dos valores.

Cabe menciona que cada pagina cuenta con su hoja de estilo y su lógica JavaScipt.
Lo cual es lo que garantiza un desarrollo modular y sostenible.
Teniendo en cuenta que se ha prestado mucha atención a los detalles de estilos,
fondo de imágenes, gradientes y efectos de interacción, 
para que el usuario pueda tener una buena experiencia al visitar la Web.
